# PyISIS v1.4.0rc3 (USGS ISIS 10.0.0)

This prerelease refreshes the version-isolated ISIS 10 wheelhouses after the
complete M08 Linux/Windows revalidation. Do not install this package line in
the same environment as the ISIS 9 package line.

## Supported configurations

- Windows x64, CPython 3.13
- Linux x86_64, CPython 3.13, `manylinux_2_35`
- Linux clean-install validation on Ubuntu 22.04, 24.04, and 26.04

macOS, ARM64, and other Python ABIs are not included.

## ISIS 10 bindings

The release retains the shared non-GUI bindings available on both ISIS 9 and
ISIS 10, plus version-gated ISIS 10 bindings for `IProj`,
`Chandrayaan2OhrcCamera`, and `Chandrayaan2TmcCamera`. Runtime validation
rejects an ISIS 9 installation with an actionable error.

## Changes since rc2

- Includes the corrected Windows PE dependency closure, including forwarded
  runtime dependencies and case-insensitive DLL indexing.
- Builds Windows bindings with Ninja in a generator-specific directory to
  prevent stale Visual Studio CMake cache failures.
- Uses a validated cached ISIS 10 Windows prefix and bounded parallel builds.
- Retains ABI audits and clean installations on three Ubuntu releases.

## Assets

- `pyisis-v1.4.0rc3-isis10.0.0-windows-x64-cp313-wheelhouse.zip`
- `pyisis-v1.4.0rc3-isis10.0.0-linux-x86_64-cp313-manylinux_2_35-wheelhouse.zip`
- `SHA256SUMS.txt`

Extract the archive for your operating system and follow its `INSTALL.md`.
Installation uses pip against the downloaded local wheelhouse; these packages
are not published to PyPI by this release.

## Important ISISDATA limitation

The included minimal ISISDATA package supports import and smoke tests only.
Real camera, SPICE, calibration, or mission processing requires a complete
external ISISDATA installation.

## Release-candidate status

This is a prerelease intended to validate public binary distribution before a
stable release. Report the operating system, Python version, ISISDATA
configuration, and failing command when opening an issue.
