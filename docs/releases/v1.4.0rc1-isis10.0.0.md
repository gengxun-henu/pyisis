# PyISIS v1.4.0rc1 (USGS ISIS 10.0.0)

This candidate was used to validate version-isolated PyISIS wheelhouses built
against USGS ISIS 10.0.0. It was not published as a GitHub Release; the first
public ISIS 10 candidate is `v1.4.0rc2-isis10.0.0`.

## Supported configurations

- Windows x64, CPython 3.13
- Linux x86_64, CPython 3.13, `manylinux_2_35`
- Linux clean-install validation on Ubuntu 22.04 and Ubuntu 24.04

macOS, ARM64, and other Python ABIs are not included.

## ISIS 10 additions

The candidate retained the shared non-GUI bindings available on both ISIS 9
and ISIS 10, and added version-gated ISIS 10 bindings for:

- `IProj`
- `Chandrayaan2OhrcCamera`
- `Chandrayaan2TmcCamera`

The package validates the selected ISIS runtime major version during import and
rejects an ISIS 9 runtime with an actionable error.
