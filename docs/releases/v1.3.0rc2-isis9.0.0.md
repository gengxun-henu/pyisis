# PyISIS v1.3.0rc2 (USGS ISIS 9.0.0)

This prerelease refreshes the GitHub-hosted wheelhouses for PyISIS built
against USGS ISIS 9.0.0 after the full ISIS 9/10 four-matrix validation.

## Supported configurations

- Windows x64, CPython 3.12
- Linux x86_64, CPython 3.12, `manylinux_2_35`
- Linux clean-install validation on Ubuntu 22.04 and Ubuntu 24.04

macOS, ARM64, and other Python ABIs are not included.

## Assets

- `pyisis-v1.3.0rc2-isis9.0.0-windows-x64-cp312-wheelhouse.zip`
- `pyisis-v1.3.0rc2-isis9.0.0-linux-x86_64-cp312-manylinux_2_35-wheelhouse.zip`
- `SHA256SUMS.txt`

Extract the archive for your operating system and follow its `INSTALL.md`.
Installation uses pip against the downloaded local wheelhouse; these packages
are not published to PyPI by this release.

## Important ISISDATA limitation

The included minimal ISISDATA package supports import and smoke tests only.
Real camera, SPICE, calibration, or mission processing requires a complete
external ISISDATA installation.

## Windows runtime packaging correction

The original ISIS 9 rc2 Windows asset omitted `openblas.dll` because runtime
staging followed normal PE imports but not PE export-forwarder targets. Clean
installations could therefore fail while importing `isis_pybind._isis_core`.
The shared staging source now follows both dependency forms. This source-only
correction does not replace the archived rc2 wheelhouse.

## Release-candidate status

This is a prerelease intended to validate public binary distribution before a
stable release. It supersedes the ISIS 9 `v1.3.0rc1` wheelhouses and includes
the Windows ISIS prefix cache-isolation corrections validated together with
the ISIS 10 release line. Please report the operating system, Python version,
ISISDATA configuration, and failing command when opening an issue.
