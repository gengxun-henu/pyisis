# PyISIS v1.4.0rc2 (USGS ISIS 10.0.0)

This prerelease provides version-isolated PyISIS wheelhouses built against
USGS ISIS 10.0.0. Do not install this package line in the same environment as
the ISIS 9 package line.

## Supported configurations

- Windows x64, CPython 3.13
- Linux x86_64, CPython 3.13, `manylinux_2_35`
- Linux clean-install validation on Ubuntu 22.04 and Ubuntu 24.04

macOS, ARM64, and other Python ABIs are not included.

## ISIS 10 additions

The release retains the shared non-GUI bindings available on both ISIS 9 and
ISIS 10, and adds version-gated ISIS 10 bindings for:

- `IProj`
- `Chandrayaan2OhrcCamera`
- `Chandrayaan2TmcCamera`

The package validates the selected ISIS runtime major version during import and
rejects an ISIS 9 runtime with an actionable error.

## Assets

- `pyisis-v1.4.0rc2-isis10.0.0-windows-x64-cp313-wheelhouse.zip`
- `pyisis-v1.4.0rc2-isis10.0.0-linux-x86_64-cp313-manylinux_2_35-wheelhouse.zip`
- `SHA256SUMS.txt`

Extract the archive for your operating system and follow its `INSTALL.md`.
Installation uses pip against the downloaded local wheelhouse; these packages
are not published to PyPI by this release.

## Important ISISDATA limitation

The included minimal ISISDATA package supports import and smoke tests only.
Real camera, SPICE, calibration, or mission processing requires a complete
external ISISDATA installation.

## Release-candidate status

This is the first public ISIS 10 prerelease and was validated together with the
ISIS 9 line across the complete Linux/Windows four-matrix workflow. It includes
the Windows SpiceQL dependency fix and version-isolated ISIS prefix cache
inputs. Please report the operating system, Python version, ISISDATA
configuration, and failing command when opening an issue.
